# Bitcoin Sentiment Analysis

## Objective
Analyze the relationship between Bitcoin market sentiment (Fear & Greed Index) and trader performance using Hyperliquid historical trading data.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Datasets
1. Bitcoin Fear & Greed Index
2. Hyperliquid Historical Trading Data

## Key Findings
- Extreme Greed showed the highest average profit.
- Fear periods had the highest trading volume.
- Win rates varied across different sentiment categories.
- Market sentiment influences trader behavior and profitability.
